## 实验一 · 星云搜索（复现 Treisman & Gelade, 1980 + 改进）

**复现**：视觉搜索范式。3D 星云中判断是否存在"珊瑚红色甜甜圈"（红 O），干扰子为薄荷绿甜甜圈与红色交叉拐杖糖（X 形）。
- 自变量：搜索类型（特征：红O 混在薄荷绿O 中 ／ 联合：红O 混在薄荷绿O+红X 中）× 集合大小（4/12/24）× 目标有无，被试内；两基线轮顺序在被试间随机平衡。
- 因变量：反应时（`performance.now()`）、正确率；核心指标为搜索斜率（ms/项）。之所以用斜率而非总反应时作为效率指标：总反应时还包含知觉、决策、按键等固定成本和区块顺序带来的练习效应，而「集合每多 1 个项目所增加的反应时」才是搜索效率的理论诊断量。
- 流程：指导语（含目标/干扰子实物图与原文出处）→ 注视记录授权 →（摄像头模式下）9 点校准 + 注视信号确认 → 练习 4 试次（有反馈，覆盖每种情形）→ 正式 3 轮 × 36 试次（轮间休息）→ 结束页（含完整文献出处）；每（类型×集合大小）条件 12 试次。

**改进（新增条件）**：第三轮为"联合搜索 + 目标特征预提示"——轮次开始时展示目标实物渲染图，且全程在屏幕上方贴出目标照片徽章。
理论依据：引导搜索模型（Guided Search, Wolfe）与特征整合理论（FIT）——自上而下的目标特征知识可引导注意，使无需逐一检查的项目被提前排除。注意：有提示区块固定在后半段，解读总反应时时需考虑练习效应的混杂，故以斜率为主要判据。

**注视记录（附加探索）**：被试自选「摄像头眼动」（WebGazer.js，9 点点击校准 + 3 秒注视信号确认，确认读到预测才放行；视频画面绝不上传，仅存注视坐标）或「鼠标轨迹代替」；摄像头打不开时会给出具体原因诊断（权限被拒绝/设备缺失/被占用/嵌套预览页拦截等）与修复指引，被试修复后可当场重试，也可主动改选鼠标。注意：嵌套预览窗口（iframe）会拦截摄像头权限，体验眼动需在新标签页单独打开链接。练习与正式试次全程记录，坐标归一化后仅存本机浏览器，结果页绘制热图并比较"有/无提示"的扫视广度。

**预测（2026-11-04 收数前写下）**：
- P1：联合搜索斜率显著大于特征搜索斜率（复现 T&G）。
- P2：预提示显著降低联合搜索斜率，但不影响特征搜索（交互作用）。本设计中一半干扰子为薄荷绿、可被颜色通道直接排除，理想降幅约为原斜率的一半；鉴于目标全程固定（被试可常驻目标模板），实际降幅可能偏小。

## 实验二 · 比例眼力（复现 Cleveland & McGill, 1984 + 改进）

**复现**：比例判断任务。判断红色 B 是紫色 A 的百分之几。
- 自变量：编码类型（位置 / 长度 / 角度 / 面积）× 作答方式（数字 / 图形），作答方式分两轮、顺序被试间随机平衡；练习 4 试次（覆盖四种编码与两种作答），正式每编码每方式 10 试次，共 80 试次。
- 因变量：|估计 − 真值|、作答时间。

**改进（新增条件）**：图形化拖拽作答——直接拖动一个**同类型**图形"画"出答案，替代数字输入。
理论依据：兼容性原理——作答表征与知觉表征兼容时，省去"知觉 → 数字"的心理转换，误差应下降；数字报告还存在已知的取整/数字偏好偏差。

**预测（2026-11-04 收数前写下）**：
- P3：误差排序复现 C&M：位置 < 长度 < 角度 < 面积。
- P4：图形作答显著降低角度与面积编码的误差（交互作用）。
- P5：数字作答的估计值显著更多落在 5/10 的倍数上（取整聚集），图形作答分布更平滑。

## 数据规范

- 被试只用匿名编号，首页先知情同意；不收集姓名学号。
- 每个实验条件完成后立即 POST `/api/hw2/submit`；experiment 名：`search` / `search_cued` / `cm` / `cm_graphic`（全小写）。
- 上传返回 `warnings` 时页面弹条提示；失败时 `try/catch` 接住并提供 CSV 备份下载。
- 调试数据用 `test_` 前缀（`js/common.js` 中 `CONFIG.DEBUG = true`），正式收数前在 /hw2 清空。
- 结果大屏（`results.html`）定时读取本项目匿名数据，绘制"预测 vs 实测"图（模型可视化），并计算配对样本效应量（Cohen's d<sub>z</sub>、t 值、显著性）与编码误差比，和原文报告的量级对照。
- 实验讲解（`learn.html`）：面向被试的"测什么 / 特别设计 / 原文出处"解读，建议实验后阅读。
